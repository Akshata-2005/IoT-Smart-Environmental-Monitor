# IoT-Based Smart Environmental Monitoring System

## Project Overview
This project focuses on the system requirements analysis and architectural design of an IoT-based smart environmental monitoring system using the ESP32 microcontroller.

The proposed device monitors indoor temperature, humidity and general air-quality variations using environmental sensors.

## Hardware Components
- ESP32 Development Board
- DHT22 Temperature and Humidity Sensor
- MQ-135 Air Quality Sensor
- OLED Display (I2C)
- Buzzer
- LED
- Regulated Power Supply

## System Features
- Temperature and humidity monitoring
- General air-quality indication
- Real-time sensor data processing
- OLED-based information display
- Threshold-based alerts
- Wi-Fi-based remote monitoring

## System Architecture
The ESP32 acts as the central controller, collecting sensor readings, processing data, controlling the display and alert units, and transmitting information through Wi-Fi.

## Communication Interfaces
- Digital communication – DHT22
- Analog input – MQ-135
- I2C – OLED display
- GPIO – Buzzer and LED
- Wi-Fi – Remote monitoring
